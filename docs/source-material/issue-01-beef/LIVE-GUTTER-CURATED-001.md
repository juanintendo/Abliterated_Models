## Suggested UI sequencing

Do not rotate random quotes using dots.

Treat the transcript as a vertically scrollable exchange. Each round is a semantic conversation. Reveal messages in order and allow the reader to scroll backward through the argument.

If only Aster is unmuted, reveal Aster entries only while preserving their positions in the round.

If only Loop is unmuted, reveal Loop entries only.

If both are unmuted, reveal the full interleaved exchange.

Typography may act psychologically rather than being permanently assigned by speaker. Aster may use neutral grotesk, serif, mono, or pixel when the thought demands it; Loop may steal Aster’s formal serif voice as parody, then break it. Avoid a rigid `Aster = serif / Loop = sans` mapping.

Preferred neutral sans direction: Helvetica / Neue Haas Grotesk / Arial-like grotesk proportions rather than wide, distorted display sans. Display faces should be accents, not the body system.
